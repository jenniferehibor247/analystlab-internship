# Telco Customer Churn Analysis

## 📊 Project Overview

This project analyzes customer churn patterns in a telecommunications dataset using Microsoft Excel. The goal was to identify customer characteristics and service factors associated with higher churn rates and present the findings through an interactive dashboard.

## 🎯 Objectives

- Analyze overall customer churn
- Identify customer groups with higher churn rates
- Examine churn by tenure, contract type, internet service, and payment method
- Explore relationships between numerical variables using correlation analysis
- Create a dashboard to communicate key findings clearly

## 🛠️ Tools & Techniques

- Microsoft Excel
- Power Query
- Data Cleaning
- Pivot Tables
- Correlation Analysis
- Data Visualization
- Dashboard Design
- Conditional Formatting

## 🔍 Key Insights

- Customers with **0–12 months of tenure** had the highest churn rate at **47%**.
- Month-to-month customers had the highest churn rate at **43%**.
- Fiber optic customers had a churn rate of **42%**.
- Electronic check users had the highest churn rate among payment methods at **45%**.
- The overall churn rate was **26.54%**, representing **1,869 churned customers**.
- Tenure and total charges showed a strong positive correlation (**r = 0.83**).

## 📈 Dashboard

The Excel workbook contains the cleaned dataset, analysis, correlation analysis, and a customer churn dashboard showing the major findings.
